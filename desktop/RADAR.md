# 隐藏宝箱雷达（实验功能）

雷达采用助手现有的 Rust / Tauri / Npcap 技术路线，共用一套采集器，不附带 Python 运行环境。协议阅读复用 `capture::framing` 的 varint 分帧和限长 LZ4 解压；TCP 缓冲按流隔离，重复数据不再次解析，缺失片段不拼接成完整数据。

公开协议参考：[Aion2-Hidden-Cube-Radar](https://github.com/benhighlanderr/Aion2-Hidden-Cube-Radar)。参考时未发现明确的再分发许可证，因此没有复制或打包该项目的 Python 程序；本实现独立编写。

## 行为

- 默认 210 × 240 逻辑像素，页面就绪时按 WebView 的实际像素比例调整原生窗口。设置在另一个窗口打开，不扩大游戏中的雷达。
- 主界面始终保留。雷达与战斗统计可分别启动或同时运行；仅开启雷达不会写入战斗统计。
- 默认不采集；点击雷达浮窗的开启按钮直接启动，不弹二次确认。采集说明保留在设置中。暂停或关闭雷达停止本功能；DPS 仍运行时保留共用采集器。
- 使用与 DPS 相同的游戏协议标记识别连接，不再限定 13320 / 13328。同方向、端点与网卡的连接须在三秒内提供十二个不同 TCP 序号的标记包；拒绝 TLS，缓存有界。独立开启雷达不启用战斗统计。加速器端口改写仍需实机验证；识别连接不代表已获得角色定位或宝箱。
- 使用自身角色记录确定实体 ID，不根据其他玩家的移动猜测角色。位置未知时不显示距离与标记；超过 5 秒未刷新时保留上次定位，距离标注“约”，状态显示定位年龄，不再反复要求重新定位。和平状态步行不保证广播坐标；冲刺、跳跃、滑翔或持武器移动有助于刷新。切图、断线重置后不沿用旧定位。
- 显示三维距离和高度差，地图正北朝上，不是跟随镜头的方位。不是全地图宝箱数据库，不能发现客户端从未收到的对象。
- 消失消息移除对应宝箱，切图清除标记。通用采集消息不能证明具体宝箱已拾取，因此不会据此删除所有附近宝箱。
- 背景与 DPS 共用材质文件、透明度设置及旧版皮肤状态，不使用外阴影。提示音、标记颜色和范围属于雷达自己的本地偏好。

## 验证边界

自动化测试覆盖白名单、实体移除、自身定位、非有限坐标、分段/重叠/重复 TCP、LZ4、切图、过期坐标、取消、重复点击、设置同步和采集生命周期。它们不代替当前游戏网络的真实定位验收。

本地修复版已在加速器连接场景收到角色坐标（2026-10-22）；尚未验证可见宝箱的标记与真实距离，仍作为实验功能提供。软件不读取游戏内存或发送游戏封包，但第三方工具仍可能涉及游戏规则风险，不能承诺反作弊豁免。
