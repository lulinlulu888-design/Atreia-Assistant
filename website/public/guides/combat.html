首次使用：安装助手与 Npcap

从官网下载安装亚特雷亚助手，再从 Npcap 官网 安装驱动。已安装 Npcap 的电脑无需重复安装，也无需下载开发用 SDK。

本助手不要求勾选 WinPcap 兼容模式。若驱动安装时限制了可使用它的账户，请按照驱动权限设置运行助手；不要为了排查而关闭系统安全保护。

建议将游戏设为窗口或无边框窗口模式，方便查看置顶统计浮窗。仅使用游戏汉化不需要安装 Npcap。

如何开启 AION2 战斗统计？

  1. 进入游戏，从助手首页选择“战斗统计”。
  2. 阅读本地网络采集提示，确认后才会开始采集；取消不会启动统计。
  3. 正常进行游戏战斗，等待助手识别游戏战斗连接。无需手动填写 IP、端口或选择加速器品牌。
  4. 通过置顶浮窗查看当前战斗数据，需要时打开统计明细。

初始连接检测可能看到本机其他程序的流量，仅在本机处理，不上传、不发送封包。工具不会注入游戏或修改游戏内存，但第三方工具仍有游戏规则风险，不能视为官方许可或安全保证。

DPS、总伤害与技能明细怎么看？

  • DPS：用于观察战斗中的每秒伤害表现，结合战斗时间与目标一起看。
  • 总伤害与玩家贡献：用于比较同一场战斗的输出构成，而不是只看某一瞬间的数字。
  • 伤害、治疗和技能明细：进一步了解数据来源与技能占比。
  • 本地战斗历史：在战斗结束后查看保留的记录，进行复盘。

切换目标、不同战斗时段或客户端更新都可能影响观察结果。官网统计面板中的数字是演示数据，不代表你的实战成绩或准确率承诺。

浮窗没有数据时，先检查什么？

  1. 确认已经选择“战斗统计”并接受采集提示。仅停留在助手首页或汉化页面不会启动统计。
  2. 检查是否提示 Npcap 未安装、未能加载或权限不足，按提示处理驱动和运行权限后重试。
  3. 确认已进入实际战斗；游戏登录界面、角色选择界面和没有战斗活动时，不一定有可统计的数据。
  4. 游戏更新后，先检查助手是否有新版。若仍无数据，记录客户端、助手版本与具体提示进行反馈。

请通过 GitHub Issues 反馈统计问题。不要公开上传包含账号、聊天内容或其他个人信息的完整网络流量文件。

停止统计，返回首页或切换汉化

在统计设置中选择“停止统计并返回首页”，停止采集后再打开“游戏汉化”。汉化和统计互斥；汉化前还需要完全退出游戏。

软件更新也应在统计停止、汉化操作结束后进行。首页可检查助手更新，由你确认后下载安装。
