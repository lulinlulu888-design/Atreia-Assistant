Windows 安装

下载 Windows 整合安装包

  1. 01

    下载

    只从本页或 GitHub Releases 下载名称为 Atreia-Assistant_版本_x64.msi 的文件。

  2. 02

    安装

    运行 MSI，安装后从桌面快捷方式打开助手。战斗统计需另行安装官方 Npcap 驱动；汉化无需启动采集。

  3. 03

    选择功能

    首页进入“游戏汉化”或“战斗统计”。汉化前请退出游戏并核对客户端目录。
