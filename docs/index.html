03 / EXPLORATION · 实验功能

宝箱雷达，小窗随行。

实验性 AION2 宝箱雷达，基于与 DPS 相同的 Rust、Tauri 和 Npcap 技术路线。紧凑浮窗展示附近隐藏宝箱、距离与高度差，独立开关，也能与战斗统计一起运行。

  • 210 × 240 紧凑窗口，减少游戏遮挡
  • 独立设置范围、透明度与提示音
  • 与 DPS 使用相同采集技术，主界面始终保留

角色定位已在本地实机观察成功；可见宝箱标记与距离尚未完成现场验收。旧定位标注为参考位置；不承诺全地图扫描或游戏规则豁免。

当前支持哪个游戏版本？

当前汉化适配 Steam Build 26077854 与 2026-10-22 更新后的 PURPLE 资源（157,521 条语言记录）。游戏更新后请重新检测；安装汉化后，将游戏文字语言设为 English。游戏内所有界面尚未逐一验收，遇到漏译可在项目仓库反馈。

使用汉化也需要安装 Npcap 吗？

仅使用汉化不需要 Npcap。开启战斗统计前，请从 Npcap 官网 安装驱动。汉化与统计独立工作。

在哪里反馈漏译或软件问题？

在 GitHub Issues 提交问题，附上助手版本、游戏客户端以及问题发生的界面。
