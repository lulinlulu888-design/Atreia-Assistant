# 亚特雷亚助手 2.0.54

- 恢复当前 PURPLE 客户端的简体中文汉化兼容，保留 Steam 已校对译文。
- 修复关闭汉化确认窗口时误提示“操作正在进行”的问题；取消后可重新操作。
- 加强战斗统计、汉化和助手更新之间的互斥保护。

本次兼容验证针对 Steam Build 25800038 和 PURPLE TW 122。两端均通过语言资源校验及隔离安装、重复安装、异常回滚、还原测试；尚未逐一验收游戏内所有界面，不保证后续游戏更新自动兼容。

下载 `Atreia-Assistant_2.0.54_x64.msi` 升级助手。升级完成后请退出游戏，在“游戏汉化”中选择对应客户端，重新检测并安装 / 更新汉化。升级助手本身不会修改游戏文件。

`build-materials.zip` 和 `localization-sources.zip` 是对应构建材料，不是玩家安装包。第三方汉化引擎的完成提示仍可能使用系统弹窗。
