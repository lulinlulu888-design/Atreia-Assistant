# 亚特雷亚助手 2.0.64

修复 Steam 汉化后界面显示 `???` 的问题。Steam 改用日文文字入口；PURPLE 继续使用原来的英文入口方案。

- **Steam / Global：文字语言选择「日本語」**。153,297 条中文文本沿用自有国服术语，附带独立的官方日文参考数据。用户已确认中文正常显示，切换到 English 再切回后仍正常。
- **PURPLE：文字语言仍选择 English**，无需日文资源。沿用已审核的 127 版补译，160,286 条文本通过缺译和编码回读检查。
- Steam 备份改用 `.bak` 扩展名，避免切换语言时把备份重新加载；兼容已知历史备份，并核对摘要后迁移。
- Steam 旧英文入口迁移会先校验和恢复原资源，再安装日文入口；资源或备份不匹配时停止操作。
- 两端使用独立组件和校验，不会因缺少组件而自动套用另一端方案。汉化窗口中的说明按客户端切换。

安装新版助手后，完全退出游戏，在「游戏汉化」中选择客户端，点击「检测」，通过后点击「安装 / 更新汉化」。仅更新助手不会自动修改游戏。语音语言保持自己的设置即可。

保留官网的下载点击统计与 S3 下载。仍使用自有中文翻译，没有直接套用参考项目的翻译 DAT。Steam 已有上述实机验收；PURPLE 本次为原方案回归验证，未把资源检查当成所有界面的实机验收。
