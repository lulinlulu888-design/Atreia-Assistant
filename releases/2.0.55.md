# 亚特雷亚助手 2.0.55

- 适配 PURPLE TW 123 与 Steam Build 25926599 的最新语言资源。
- 修复新版语言包内部路径大小写变化导致的读取兼容问题。
- 补充活动、道具、货币及转服规则译文，保留 Steam 已校对译文与本端数值；“Trick or Treat”现显示为“不给糖就捣蛋”。

两端通过语言资源校验、独立解码及隔离安装、重复安装、异常回滚、还原测试。PURPLE 另由用户在助手内手动批准真实安装，实际译文文件与验收产物一致。尚未逐一验收游戏内所有界面，不保证后续游戏更新自动兼容。

下载 `Atreia-Assistant_2.0.55_x64.msi` 升级助手。升级完成后请退出游戏，在“游戏汉化”中选择对应客户端，重新检测并安装 / 更新汉化。升级助手本身不会修改游戏文件。

`build-materials.zip` 和 `localization-sources.zip` 是对应构建材料，不是玩家安装包。第三方汉化引擎的完成提示仍可能使用系统弹窗。
