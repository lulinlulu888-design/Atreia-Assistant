## 安装与更新

下载 `Atreia-Assistant_2.0.50_x64.msi`。更新前结束统计及汉化操作并关闭助手。安装助手不会自动修改游戏；退出游戏后，在助手内重新检测并安装汉化。Npcap 和 WebView2 运行时不包含在安装包内。MSI 未做发布者代码签名。

## 构建材料

应用对应源码由 Git 标签 `v2.0.50` 提供。Release 构建材料包附带补译资源、原引擎源码、原始组件、依赖源代码包及说明，组件各自许可见 `THIRD_PARTY_NOTICES.md` 和随包 notices。

桌面发布前运行 `python prepare-desktop-notices.py <new-directory> --fetch-missing`，再将输出复制到 `desktop/src-tauri/vendor/notices/`。脚本优先收集本地锁定依赖的许可，缺失时按 crate 中的提交获取上游工作区许可；少数旧 crate 缺少独立文本的情况在脚本中明确记录。此技术清单不构成法律意见。
