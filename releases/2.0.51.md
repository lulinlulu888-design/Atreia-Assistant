# 亚特雷亚助手 2.0.51

- 官网重新设计：全幅云海浮岛场景、新羽翼“2”标志、版本动态、功能展示与使用指南。
- 软件窗口和应用图标采用新标志；MSI 使用中文安装界面及游戏风格配图。
- 更新检查在 GitHub API 限流或连接失败时，读取项目官网的备用更新记录。下载仍核对同仓库发布地址、版本、完整 SHA-256 与文件大小。
- 修复重复显示“更新检查失败”的提示。
- 游戏目录为空时，点击“检测”自动查找所选客户端的安装位置。Steam 支持额外游戏库和安装清单；PURPLE 检查常见安装位置与 Windows 安装记录。
- 检测出多个目录时需选择目标；新增文件夹浏览按钮。切换客户端时清空旧目标。

本机只读验证已自动找到 Steam 与 PURPLE 安装目录，自动发现的 Steam 目录通过 152,774 条语言记录的合并、编码回读和缺译检查。检测未修改游戏。PURPLE 目录发现成功不代表其当前语言资源已兼容，汉化支持范围继续见 [2.0.50 验证记录](2.0.50.md)。

自动更新备用源采用与 GitHub API 相同的发布记录结构。仅接受同仓库正式版本的 Windows x64 MSI，缺少摘要、大小不符或来源不符均拒绝安装。该更新协议与此前一样基于 HTTPS 元数据，未使用独立发布者代码签名。

安装前结束正在进行的助手操作并关闭旧版。2.0.50 的更新检查遇到 403 时，请从官网下载 2.0.51 手动更新。新图标和安装器配图随 2.0.51 生效，不修改已经发布的 2.0.50 文件。
