# 亚特雷亚助手 UI 与交互规范

适用于 Atreia-Assistant 的 Tauri 桌面端。先读取当前实现和测试，保留现有功能与用户改动；本规范不授权发布、更新真实游戏文件或开启抓包。

## 视觉与窗口

- 共享样式入口为 `desktop/src/neumorphic.css`；主页、汉化弹层、确认窗口、统计和设置使用同一套浅色新拟态材质。颜色、阴影优先复用 token，不为单页复制整套主题。
- 凹面用于输入与状态，凸面用于可点击按钮和卡片；主操作使用青绿色。不能仅靠阴影或颜色表达状态，保留清楚的文字、键盘焦点和禁用状态。
- 主页默认客户区 680 × 500，无滚动条；长提示保留完整可访问文本。调整默认尺寸时同步检查 Windows 缩放和紧凑视口，而非只隐藏溢出。
- 内容多的子窗口允许内容区滚动，操作区固定可达；保留统计悬浮窗的透明度、布局和主题选项。尊重 reduced-motion 与 forced-colors。

## 汉化与导航

- 检测是只读操作；目录为空时按所选客户端发现安装目录。零个候选解释原因，多个候选让用户选择，不猜测目标。
- 安装需当前客户端及目录检测成功；更改客户端、目录或完成写入使检测状态失效。后端仍独立校验路径、组件、资源兼容性和游戏进程，前端状态不是授权。
- 取消目录选择不清空原目录。返回主页恢复入口焦点，保留本次会话的客户端及目录，但重新进入不缓存兼容性批准。
- 等待操作时禁止重复执行、切换目标和返回，说明当前等待的是确认还是执行；异常及取消后恢复控件。不要以杀进程、超时中断安装或还原来实现“返回”。

## 确认与安全

- 应用自身确认使用 `confirmation.html` 和后端 `atreia_confirmation`，展示中文操作名称、规范化目标与客户端、具体风险；不展示 install/restore 作为面向用户的动作名。
- 默认焦点在取消；Escape、窗口关闭和信息加载失败均不得解释为同意。确认失败保持可取消，不自动重试写入。
- 后端拥有请求，只有专用窗口能答复，批准单次使用并关联请求 ID。调用端传入布尔值不能绕过授权。等待确认期间保留已有忙碌/事务保护。
- 系统目录选择器可以保持原生样式。固定版本第三方汉化引擎的完成提示可能仍是原生 MessageBox；没有改动及验证引擎前，不宣称所有弹窗已经统一。
- 备份、回滚、游戏关闭检查、组件哈希和客户端隔离不得为了视觉统一而削弱。开启统计抓包、安装汉化、还原及下载更新仍是明确的用户操作。

## 验证与交付

测试覆盖检测成功/失败/多候选、目录变化、取消、重复点击、等待时返回、返回后重入、确认加载失败、过期批准和非专用窗口答复。执行现有 Node 测试、Rust 测试与前端构建；对变更窗口做实际布局检查。

真实桌面验证优先只读检测和取消确认。未经本次授权不点击真实游戏写入确认；模拟数据只证明 UI 行为，不证明新游戏版本兼容。交付明确区分自动化测试、实际桌面验证、真实安装验证以及未覆盖的第三方提示。

仅有 UI 修改不代表要更新官网版本记录或创建正式 Release。若任务要求发布，再同步版本、构建材料和发布证据；个人 skill 的安装副本应与仓库的此文件保持一致。
