# 亚特雷亚助手｜永恒之塔2汉化工具与 DPS 战斗统计

**Atreia Assistant** 是面向《永恒之塔2》（AION2 / AION 2）玩家的开源社区工具，将游戏汉化和战斗统计分为两个独立入口。

打开助手，选择你需要的功能：**战斗统计**或**游戏汉化**。只有开启统计后才显示游戏悬浮窗。

> 当前为开发测试版，尚未发布正式整合安装包。桌面汉化入口已接入 Steam / Global 与 PURPLE，使用各端当前英文语言表生成汉化，不直接覆盖为另一端的旧语言表。两端当前资源的缺键补译、隔离安装、重复安装、故障回滚、更新后备份分代和逐字节还原已验证；游戏内显示仍待验证。维护与验证范围见 [双端汉化说明](localization/README.md)。

## 战斗统计

- 小型透明置顶浮窗，查看 DPS、总伤害、玩家贡献及技能明细。
- 支持伤害、治疗分析和本地战斗历史。
- 自动检测游戏战斗通道，无需手动填写 IP、端口或选择加速器品牌。
- 在统计设置中选择“停止统计并返回首页”，再使用独立的汉化功能。
- 统计窗口不提供汉化、第三方账号登录、赞助或日志上传入口。

首次使用需安装 [Npcap 驱动](https://npcap.com/#download)，已安装则无需重复安装。无需下载 SDK，也不要求勾选 WinPcap 兼容模式。建议使用游戏的窗口或无边框窗口模式。

## 游戏汉化

永恒之塔2 Steam / Global 与 PURPLE 简体中文汉化功能，提供检测、安装、更新与还原入口。汉化时请先退出游戏，并确认客户端和游戏目录。整合版调用独立汉化组件；源码仓库不附带该组件、解压依赖或游戏语言数据。PURPLE 补译从本地官方繁体中文表转换，并绑定原英文文本摘要，避免游戏更新后误套旧译文。

目前需要正式版 Steam 汉化工具的玩家，请前往 [Aion2-Steam-CN 正式 Release 下载页面](https://github.com/lulinlulu888-design/Aion2-Steam-CN/releases/latest)，在 Assets 中只下载对应的 **.exe 安装文件**，无需下载 Source code。

## 使用流程

1. 启动亚特雷亚助手，选择“战斗统计”或“游戏汉化”。
2. 战斗统计：进入游戏后开启统计，确认采集提示，查看浮窗数据。
3. 游戏汉化：退出游戏，选择游戏目录，执行检测、安装或还原。

两项功能相互独立。打开首页或汉化页面不会启动抓包，汉化功能也不放在统计浮窗里。

## 开发与构建

Windows 开发环境需 Node.js 24、Rust 1.93 和对应的 Tauri 编译依赖。在仓库根目录运行：

```powershell
./build-desktop.ps1 -DebugBuild
```

脚本生成界面资源、运行前端测试并编译桌面程序，不启动抓包或修改游戏。可选汉化组件的接入方式见 [桌面整合说明](desktop/ATREIA-FORK.md)。GitHub Actions 检查前端、Rust 测试和 Windows 桌面构建。

早期 Python/Tk 原型、协议后端接口及详细测试范围保留在 [旧版开发说明](LEGACY_DEVELOPMENT.md)，不作为新版玩家操作教程。
